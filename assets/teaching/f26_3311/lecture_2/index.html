Composing multiplicative symmetries

In the last lecture, we considered the symmetries of the set

\[\mu_5=\{1,\zeta_5,\zeta_5^2,\zeta_5^3,\zeta_5^4\}\]

equipped with its multiplicative structure. There are exactly four such symmetries, $\sigma_1,\sigma_2,\sigma_3,\sigma_4$, where $\sigma_i$ raises each root to the $i$th power.

Two bijections from a set to itself can be composed. Composing these four symmetries never takes us outside the same collection: the set $\{\sigma_1,\sigma_2,\sigma_3,\sigma_4\}$ is closed under composition. Indeed,

\[\sigma_i\circ\sigma_j=\sigma_{ij},\]

where the subscript is read modulo $5$.

Composition of the four multiplicative symmetries
$\circ$ $\sigma_1$ $\sigma_2$ $\sigma_3$ $\sigma_4$
$\sigma_1$$\sigma_1$$\sigma_2$$\sigma_3$$\sigma_4$
$\sigma_2$$\sigma_2$$\sigma_4$$\sigma_1$$\sigma_3$
$\sigma_3$$\sigma_3$$\sigma_1$$\sigma_4$$\sigma_2$
$\sigma_4$$\sigma_4$$\sigma_3$$\sigma_2$$\sigma_1$

If we remember only the subscripts, this is multiplication modulo $5$:

Multiplication of nonzero residue classes modulo $5$
$\cdot$$1$$2$$3$$4$
$1$$1$$2$$3$$4$
$2$$2$$4$$1$$3$
$3$$3$$1$$4$$2$
$4$$4$$3$$2$$1$

The structure being preserved

There are $4!=24$ ways to shuffle the four nontrivial fifth roots. What makes these four particular symmetries special?

The fifth roots of unity are not a random collection of five objects. They have a multiplicative structure: multiplying two roots gives another root, and

\[\zeta_5^i\cdot\zeta_5^j=\zeta_5^{i+j}.\]

Since $\zeta_5^5=1$, only the remainder of an exponent modulo $5$ matters.

Multiplication of the fifth roots of unity
$\cdot$$1$$\zeta_5$$\zeta_5^2$$\zeta_5^3$$\zeta_5^4$
$1$$1$$\zeta_5$$\zeta_5^2$$\zeta_5^3$$\zeta_5^4$
$\zeta_5$$\zeta_5$$\zeta_5^2$$\zeta_5^3$$\zeta_5^4$$1$
$\zeta_5^2$$\zeta_5^2$$\zeta_5^3$$\zeta_5^4$$1$$\zeta_5$
$\zeta_5^3$$\zeta_5^3$$\zeta_5^4$$1$$\zeta_5$$\zeta_5^2$
$\zeta_5^4$$\zeta_5^4$$1$$\zeta_5$$\zeta_5^2$$\zeta_5^3$

If we keep only the exponents, regarding $1$ as $\zeta_5^0$, the same information becomes addition modulo $5$:

Addition modulo $5$
$+$$0$$1$$2$$3$$4$
$0$$0$$1$$2$$3$$4$
$1$$1$$2$$3$$4$$0$
$2$$2$$3$$4$$0$$1$
$3$$3$$4$$0$$1$$2$
$4$$4$$0$$1$$2$$3$

The last two tables are the same up to relabeling the rows, columns, and entries. We will formalize this idea in later lectures.

Which bijections preserve multiplication?

Observation

The identity, squaring, cubing, and fourth-power maps are precisely the bijections

\[\sigma:\mu_5\longrightarrow\mu_5\]

that preserve the multiplicative structure. More precisely, they satisfy

\[\sigma(\zeta_5^i)\sigma(\zeta_5^j)=\sigma(\zeta_5^{i+j})\]

for all $i,j\in\{0,1,2,3,4\}$.

Proof

First, a multiplicative symmetry $\sigma$ must fix $1$. For every $j$,

\[\sigma(1)\sigma(\zeta_5^j)=\sigma(\zeta_5^0)\sigma(\zeta_5^j)=\sigma(\zeta_5^{0+j})=\sigma(\zeta_5^j).\]

Because $\sigma(\zeta_5^j)\ne0$, cancellation gives $\sigma(1)=1$.

There are therefore four possible values for $\sigma(\zeta_5)$: $\zeta_5,\zeta_5^2,\zeta_5^3,$ or $\zeta_5^4$. Once this value is chosen, preservation of multiplication determines every other value. If $\sigma(\zeta_5)=\zeta_5^k$, for example, then

\[\sigma(\zeta_5^2)=\sigma(\zeta_5)\sigma(\zeta_5)=\zeta_5^{2k}.\]

Similarly, $\sigma(\zeta_5^3)=\zeta_5^{3k}$ and $\sigma(\zeta_5^4)=\zeta_5^{4k}$. The four choices for $k$ give exactly the identity, squaring, cubing, and fourth-power symmetries.

Rigid symmetries of the pentagon

There is another, geometric structure on $\mu_5$: its elements are the vertices of a regular pentagon. We can therefore consider the rigid symmetries that preserve the pentagon's perimeter and adjacency.

Reflections

Reflecting across the median through the vertex $1$ is complex conjugation, the multiplicative symmetry $\sigma_4$. It fixes $1$ and exchanges the other four roots in pairs.

Rotations

We can also rotate the pentagon through an integer multiple of $2\pi/5$. Rotation counterclockwise by one step gives

\[1\longmapsto\zeta_5\longmapsto\zeta_5^2\longmapsto\zeta_5^3\longmapsto\zeta_5^4\longmapsto1.\]

This preserves the rigid geometry of the pentagon, but it does not preserve multiplication. For example, rotating the equality $1\cdot1=1$ by one step would produce the false equality $\zeta_5\cdot\zeta_5=\zeta_5$.
